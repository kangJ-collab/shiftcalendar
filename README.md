# 교대달력

교대근무 일정과 연차를 관리하고 예상 급여를 확인하는 앱입니다.

[앱 사용하기](https://kangj-collab.github.io/shiftcalendar/) · [Android 앱 받기](https://github.com/kangJ-collab/ShiftCalendarAndroid/releases/latest)

## 주요 기능

- 교대근무 일정과 메모 관리
- 연차 사용·잔여일수 확인
- 월별 예상 급여와 개인별 항목 설정
- 데이터 백업·복원

## 사용 안내

처음 사용할 때 설정에서 근무조와 필요한 항목을 입력하세요. 달력에서 근무와 메모를 수정하고, 급여 화면에서 월별 예상 금액을 확인할 수 있습니다.

## 설치와 백업

휴대폰 브라우저의 ‘앱 설치’ 또는 ‘홈 화면에 추가’로 설치할 수 있습니다.

기기를 변경하기 전에는 설정의 백업 기능으로 데이터를 보관하세요.
